CS 201 — Systems / Toolchain Setup

Installing avr-gcc and avrdude

Set up the AVR compiler and flashing tool outside the Arduino IDE, so your Makefile-based workflow works the same on a Mac or a Windows machine.

Using Git Bash on Windows? Start there — most commands below will match what your Mac classmates are running.

Pick your OS

macOS →

Homebrew install, two commands, no PATH editing.

Windows →

Manual download, extract, add to PATH.

Quick check

Once installed, confirm both tools are on your PATH:

avr-gcc --version
avrdude -v

If either command isn't found, see PATH, explained before continuing.
